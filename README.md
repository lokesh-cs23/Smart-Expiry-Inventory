# Smart Expiry Management System with Automated Email Alerts

## 📌 Project Overview

The Smart Expiry Management System is a full-stack web application developed to help users track and manage the expiry dates of products such as groceries, medicines, cosmetics, and household items. The system automatically monitors product expiry dates and sends email notifications when products are nearing expiration, helping users reduce wastage and improve inventory management.

---

## 🚀 Features

- Add, edit, delete, and manage product details
- Track product expiry dates efficiently
- Automated email alerts for expiring products
- Dashboard displaying product statistics
- Product categorization and inventory management
- Responsive and user-friendly interface
- PostgreSQL database integration
- Automated expiry monitoring using Cron Jobs

## ⚙️ How the System Works

1. Users add product details such as:
   - Product Name
   - Category
   - Quantity
   - Expiry Date
   - Email Address

2. Product information is stored securely in the PostgreSQL database.

3. The expiry monitoring service automatically checks product expiry dates at scheduled intervals.

4. When a product is close to its expiry date, the system sends an automated email notification to the user.

5. Users can monitor product status and statistics through the dashboard.
